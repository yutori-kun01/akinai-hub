# Tips販売ページ原稿（未公開・条件確定前）

## タイトル案
教材販売・メルマガ・購入者サイトを、自分の環境に。買い切り Akinai hub

## 紹介文
販売ページ、商品、顧客、メール、購入者への受け渡し。
別々に管理していた作業を、自分のCloudflare上にまとめるツールです。

ツールの利用権は買い切り。自分のアカウントで運営するので、顧客データと販売データを手元に持てます。

銀行振込・Stripeのカード決済、タグ別メール、時間差のステップ配信、講座、本棚、ファイル納品に対応。メールはResend・Brevo・SendGrid・Mailgun・Postmarkから選択できます。

## 含まれるもの
- 自分のCloudflareへ設置するソースZIP
- 導入ウィザードと日本語マニュアル
- 商品・顧客・メール・講座・販売ページの管理画面
- 配信通知と送信抑止、定期実行、バックアップ・復元

## 購入前に確認してください
セルフホスト型です。初期導入にはPCとターミナル操作が必要です。Cloudflare、送信ドメイン、メール配信会社、Stripeなどの外部費用は別途かかる場合があります。無料運用やメール到達、売上は保証しません。

UTAGEとの完全互換ではありません。複雑な分岐、サブスクリプション決済、アフィリエイト管理は含みません。メール本文はテキスト形式、ステップは時間差指定です。ブロック式ページビルダー、本人確認付きオプトイン、LINEテキスト配信に対応。1回の自動処理でメール10件・LINE10件を送る小規模運用向けです。
