# イベント予約とパートナー（rc.3 第3回）

## イベント・予約（管理画面「イベント」）

- 1つのイベントに日程（開始日時・時間・定員・補足）を最大50件。公開すると `/events/<店舗>/<URL末尾>` で予約を受け付けます。
- 予約にはメールの本人確認（6桁コード）が必要です。同じ日程の二重予約はできず、定員を超える予約は同時刻に押されても入りません（席ごとの確保）。
- 予約すると、予約確認メールと、開始の何時間前かを指定したリマインド（既定 24時間前・1時間前、最大3つ）を取引メールとして送ります。キャンセル（予約者本人・管理者）で未送信のリマインドは止まります。
- 参加URL（Zoom・Google Meet等）は予約した人のページとメールにだけ表示します。Googleカレンダーへの追加リンクと予定ファイル（.ics）を用意しています。
- 「購入者のみ」を選ぶと、指定商品の入金済み購入者だけが予約できます。予約時に付けるタグでステップ配信を始められます。
- 予約のある日程は日時の変更・削除ができません（先に予約をキャンセル）。予約者はCSVで出力できます。
- バックアップ復元時は、予約データから席の確保状態を作り直します。

未対応：Zoom/Google Meetの会議URL自動発行、Googleカレンダーへの直接登録（API）、有料イベントの決済連動、キャンセル待ち、予約フォームの追加項目。

## パートナー（アフィリエイト。管理画面「パートナー」）

- パートナーごとに紹介コード、報酬（売上の％または1件ごとの定額）、状態を設定します。
- 販売ページ・イベントページのURLに `?aff=<紹介コード>` を付けて紹介してもらいます。クリックから30日間、最後に踏んだリンクが有効です（Cookie）。
- 期間内の申込は注文に紹介元が記録され、オーダーバンプ・ワンクリックアップセルも同じ紹介元になります。パートナー本人のメールアドレスでの購入は対象外です。
- 報酬は**入金済み**の注文だけを、日本時間の申込月ごとに数えます。終わった月を「承認」すると金額が確定し（後の返金等では変わりません）、振込は手動で行って「支払済み」にします。CSVで出力できます。
- パートナーは `/partner` に購入者と同じメールログインで入り、自分の紹介リンクと月ごとの成果を確認できます。

未対応：案件・パートナーグループ別の報酬、多段階報酬、クリック数の集計、報酬の自動振込、承認後の返金の差し引き。
