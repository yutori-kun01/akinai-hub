# 決済（継続課金・分割・オーダーバンプ・アップセル・クーポン）

2026-10-14追加。外部APIは統合テストで模擬しており、Stripeテストモードでの実接続確認は未実施です。

## 支払い方法（商品ごと）

| 種類 | 内容 | 銀行振込 |
| --- | --- | --- |
| 一括払い | 従来どおり。カードはStripe Checkout（カードを保存し、直後のアップセルに使用） | ○ |
| 継続課金 | 毎月／毎年。無料お試し日数を設定可。購入者は本棚から解約でき、期間末まで利用可。解約・失敗が確定すると利用停止 | × |
| 分割払い | 総額を回数で割り（1円未満切り上げ）毎月請求。最終回の支払い後に自動終了し、その後も利用可 | × |

- 継続課金・分割は 50円以上、カードのみ。
- 支払い失敗時は「支払い失敗」と表示し、Stripeの再試行が尽きて契約が終了した時点で利用停止にします。
- 管理画面で継続課金の注文を「利用停止」にすると、Stripeの契約も即時に解約します。

## オーダーバンプ

販売ページで「同時購入の商品」を選ぶと、申込フォームにチェックボックスが出ます。一括払い同士のみ。カードは1回のCheckoutで合計を決済、銀行振込は1通の案内メールに合計を記載し、本体の入金確認で同時購入分も入金済みになります。同時購入した人だけ別の完了ページへ送ることもできます。

## ワンクリックアップセル

1. ページの種類「アップセル」で追加の商品（一括払い）を選び、「購入した場合の次のページ」「断った場合の次のページ」を設定。
2. 販売ページの「登録・申込後の次のページ」にアップセルページを選ぶ。
3. 購入直後に `?order=<注文ID>` 付きでアップセルページを表示。「はい」で直前と同じカードに追加請求します（カード会社の認証が必要な場合はCheckoutへ移動）。銀行振込の注文の後は振込の申込になります。
4. アップセルを連ねる（ダウンセル）こともできます。

同じ画面での二重クリックは同じ注文キーで処理され、二重請求しません。他人の注文IDでは実行できません。

## クーポン

- 割引率（%）または割引額（円）。対象商品・期間・利用回数の上限を設定できます。
- 販売フォームで入力するか、URL末尾に `?coupon=コード`。割引は本体のみ（同時購入には適用しない）。
- 100%割引で合計0円になった一括払いは決済なしで申込完了になります。
- 継続課金では毎回の請求額に適用されます。

## Stripe Webhookで受け取るイベント

`checkout.session.completed` / `checkout.session.async_payment_succeeded` / `payment_intent.succeeded` / `invoice.paid` / `invoice.payment_failed` / `customer.subscription.deleted`

同じイベントの再送は無視し、金額・通貨・セッションIDが注文と一致しないものは拒否します。

## 支払い失敗の通知（第3回）
継続課金・分割払いの請求失敗（Stripe `invoice.payment_failed`）は、管理画面の「運営のお知らせ」に1回だけ表示し、メール送信が有効なら管理者のメールアドレスにも送ります（同じイベントの再送では重複しません。送信失敗は記録のみで自動再送しません）。
