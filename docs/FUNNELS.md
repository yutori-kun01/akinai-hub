# ページビルダーと登録導線 — 1.0.0-rc.2

「ページ・フォーム」で新規作成。販売ページ、オプトイン、完了・案内ページの3種類から選びます。

## ページを組み立てる

- 見出し、本文、画像、動画、ボタン、登録・申込フォーム、カウントダウン、区切り線を追加（最大50ブロック）。上下ボタンで順序変更。フォームは1つまで。
- 文字の左・中央揃え、白・薄いブルー・アクセント背景、ページのアクセント色を設定。
- 画像はHTTPSの画像URL。動画はYouTube / Vimeo URL。画像の説明も入力してください。外部メディア本体はバックアップに含まれず、URLのみ保存します。
- ボタンリンクに #registration を指定するとフォームへ移動。任意HTML・JavaScriptは受け付けません。
- 編集中のライブプレビューはデスクトップ幅と375pxのスマホ幅を切り替えられます。端末別のスタイル保存や自由配置、ドラッグ操作はありません。
- 受付期限は日本時間で指定。期限切れは表示だけでなく登録・申込APIでも拒否。
- フォームを置かなければページ末尾に自動表示。完了ページにはフォームを置かず、案内とリンクを配置してください。
- 「有効」はページを提供可能にする状態です。Sitesの非公開設定を一般公開に変える操作ではありません。独立ホスティング版では公開URLになります。

## メール登録

1. 運営情報にプライバシーポリシーを保存し、メール認証を設定。
2. 完了ページを作り、有効にする。
3. オプトインページを作り、登録方法をメール、登録タグを指定。完了ページを選ぶ。
4. ステップ配信に同じ対象タグを設定して有効化。
5. 訪問者が名前・メール・配信同意を入力し、メールに届いたコードで本人確認。既にログインしている場合は認証済みのメールを使用。
6. 登録後、タグ・同意文面／ページ版／確認日時を保存し、ステップを予約。重複登録でステップが再送されることはありません。
7. 配信はCronとMAIL_ENABLEDによって実行。認証メール以外はフォーム送信時に直接送りません。

解除・バウンス・苦情で停止されているメールを、公開フォームで勝手に復活させません。再登録は販売者へ問い合わせる案内になります。

## 販売と完了ページ

販売ページには有効な商品を選択。銀行振込申込後／Stripeの成功遷移先に、有効な完了ページを指定できます。指定がない場合は購入者の本棚。完了ページの表示は入金確認にはなりません。納品可否は注文の入金状態で判定します。

## 配信条件

メール・LINEの配信とステップは、対象タグ、除外タグ、「この商品の購入後は送らない」「この商品の購入者だけに送る」を設定できます。送信直前にも条件を確認します。購入済みは paid の注文で判定します。対象タグの有無だけで未入金者を購入済みにはしません。

購入前ステップに停止商品、購入後ステップに購入必須商品を設定すると切替できます。LINEではメール顧客とのアカウント連携が必要です。

配信準備済みの日時指定キャンペーンと有効なステップはCronが予約します。「予約」「対象者を登録」で即時にキュー作成も可能。一度予約した本文・配信先種別・ステップ構成・日時は変更不可。状態や対象条件は変更でき、一時停止も可能です。新しい内容は新規配信として作成してください。

未対応：複数ページを俯瞰するフロー図、分岐ツリー、A/Bテスト、端末別細部編集、セッション別期限、開封・クリック連動、フォーム任意項目、HTMLメール、定期決済。
