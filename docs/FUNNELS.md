# ページビルダーと登録導線 — 1.0.0-rc.2 ＋ 2026-10-14 追加分

「ページ・フォーム」で新規作成。販売ページ、オプトイン、完了・案内ページの3種類から選びます。

## ページを組み立てる

- 見出し、本文、画像、動画、ボタン、登録・申込フォーム、カウントダウン、区切り線を追加（最大50ブロック）。⠿ハンドルのドラッグ（PC）または上下ボタン（スマホ・キーボード）で順序変更。ブロックの複製可。フォームは1つまで（フォームは複製不可）。
- ブロックが空のときは「販売ページ」「無料登録ページ」「完了ページ」のテンプレートで始められます。通常のブロックを挿入するだけなので、挿入後は自由に編集・削除できます。文面は仮のたたき台です。
- ブロックごとに「すべての端末／PCのみ／スマホのみ」を指定できます（幅600px以下をスマホとして判定）。既存ページのブロックは「すべての端末」として扱います。
- 文字の左・中央揃え、白・薄いブルー・アクセント背景、ページのアクセント色を設定。
- 画像はHTTPSの画像URL、または画像ブロックから直接アップロード（PNG・JPEG・WebP・GIF、5MB以下。ファイル内容で形式を判定し、SVGやHTMLは拒否）。アップロード画像はR2の `<店舗>/images/` に保存され、公開ページから誰でも閲覧できます。納品ファイルとは別の領域で、納品ファイルがこのURLから取得されることはありません。ページで使用中のアップロード画像はバックアップに含まれ、復元時は同じURLに戻ります。外部URLの画像・動画本体はバックアップに含まれず、URLのみ保存します。
- ボタンリンクに #registration を指定するとフォームへ移動。任意HTML・JavaScriptは受け付けません。
- 編集中のライブプレビューはデスクトップ幅と375pxのスマホ幅を切り替えられます。ブロック単位の端末別表示のみで、端末別の文字サイズ・余白などの細部調整や自由配置はありません。
- 受付期限は日本時間で指定。期限切れは表示だけでなく登録・申込APIでも拒否。
- フォームを置かなければページ末尾に自動表示。完了ページにはフォームを置かず、案内とリンクを配置してください。
- 「有効」はページを提供可能にする状態です。Sitesの非公開設定を一般公開に変える操作ではありません。独立ホスティング版では公開URLになります。

## メール登録

1. 運営情報にプライバシーポリシーを保存し、メール認証を設定。
2. 完了ページを作り、有効にする。
3. オプトインページを作り、登録方法をメール、登録タグを指定。完了ページを選ぶ。
4. ステップ配信に同じ対象タグを設定して有効化。
5. 訪問者が名前・メール・配信同意を入力し、メールに届いたコードで本人確認。既にログインしている場合は認証済みのメールを使用。
6. 登録後、タグ・同意文面／ページ版／確認日時を保存し、ステップを予約。重複登録でステップが再送されることはありません。
7. 配信はCronとMAIL_ENABLEDによって実行。認証メール以外はフォーム送信時に直接送りません。

解除・バウンス・苦情で停止されているメールを、公開フォームで勝手に復活させません。再登録は販売者へ問い合わせる案内になります。

## 販売と完了ページ

販売ページには有効な商品を選択。銀行振込申込後／Stripeの成功遷移先に、有効な完了ページを指定できます。指定がない場合は購入者の本棚。完了ページの表示は入金確認にはなりません。納品可否は注文の入金状態で判定します。

## 配信条件

メール・LINEの配信とステップは、対象タグ、除外タグ、「この商品の購入後は送らない」「この商品の購入者だけに送る」を設定できます。送信直前にも条件を確認します。購入済みは paid の注文で判定します。対象タグの有無だけで未入金者を購入済みにはしません。

購入前ステップに停止商品、購入後ステップに購入必須商品を設定すると切替できます。LINEではメール顧客とのアカウント連携が必要です。

配信準備済みの日時指定キャンペーンと有効なステップはCronが予約します。「予約」「対象者を登録」で即時にキュー作成も可能。一度予約した本文・配信先種別・ステップ構成・日時は変更不可。状態や対象条件は変更でき、一時停止も可能です。新しい内容は新規配信として作成してください。

未対応：複数ページを俯瞰するフロー図、分岐ツリー、A/Bテスト、端末別の細部スタイル編集、画像の一覧管理・削除UI、セッション別期限、開封・クリック連動、フォーム任意項目、HTMLメール、定期決済。

## 公開ページの見た目（2026-10-19 追加）

- 本文・見出し・吹き出しの中で `**太字**` と `==マーカー==` が使えます。HTMLは解釈しません（文字としてそのまま表示）。
- 追加ブロック
  - 吹き出し：本文＝話す内容、説明欄＝話す人の名前、URL＝アイコン画像（任意。アップロード可・バックアップ対象）
  - お客さんの声：本文＝感想、説明欄＝誰の声か。ご本人の許可を得たものだけ掲載してください
  - よくある質問：1行目が質問、2行目以降が回答
  - チェックリスト：1行に1項目。`❌` で始まる行は「向いていない」として表示
- 背景の「薄いアクセント色」とマーカーの色は、ページのアクセント色から作ります。
- ヘッダーには運営情報の店舗名を表示します。ページのタイトル・説明（共有時の表示）はページタイトルと最初の本文から作ります。
- スマホ幅では、フォームのあるページで、読み進めるとフォームへのボタンが画面下に出ます（フォームが見えている間は隠れます）。
- 完了ページの「購入者の本棚へ」は、販売ページの完了ページとして選ばれているページにだけ表示します。
