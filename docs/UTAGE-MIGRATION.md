## 保存単位

| 区分 | 原文・設定として保存するもの |
|---|---|
| メール | 件名、HTML原文、テキスト本文、改行・余白・装飾、送信者名、送信元、返信先、フッター、画像、リンク、差し込み変数 |
| ステップ | シナリオ名/ID、ステップID、順序、開始条件、相対時間/固定時刻、タイムゾーン、曜日条件、除外条件、有効/停止状態、前後アクション |
| 商品 | 商品ID、商品名、説明、価格、税込/税抜、決済方法、支払回数、販売状態、申込完了後URL、納品・会員サイト・シナリオへの関連 |
| ファネル | ファネル/ページID、URL、ページ順序、HTML/CSS、フォーム、完了ページ、期限・カウントダウンの起算条件、遷移先 |
| 顧客・タグ | メール、登録日時、タグ/ラベルIDと名前、同意、停止・エラー、シナリオ登録状況、配信進捗。必要範囲のみ |
| 会員サイト | コース/レッスンID、順序、本文、画像/動画/配布ファイルURL、公開条件、購入商品との紐付け |

## 保存形式

- 原本: 取得したHTML・TXT・CSV・JSONと画像/配布ファイルを変更せず保持。
- manifest.json: 取得日時（JST）、取得元URL/ID、ファイル名、SHA-256、種類、取得完了/未取得、照合結果。
- relations.json: 商品→申込→完了ページ→シナリオ→講座の関係。
- migration-map.csv: 元ID→新ID、対応可能/要変換/未対応、変換内容、承認状態。
- プレビュー: 原文と新環境表示を比較できるHTML。差し込み変数を勝手に確定値へ変えない。

## 取得時のルール

UTAGE側の内容は変更しない。配信・予約・公開・販売状態を操作しない。ページ分割・アーカイブ・停止中も確認。本文だけで保存完了とせず、配信時刻と対象条件、フッターの継承も照合する。画像はURLだけでなく可能なら実ファイルを保存し、取得できなければ明示する。

## 移行時のルール

原本と変換版を分ける。今のツールが表現できないLINEリッチ配信・既存アカウント識別子の自動対応、複雑な条件分岐、HTMLメール装飾、差し込み変数、固定時刻ステップ、リマインドなどを単純な時間差に黙って置き換えない。

初回はすべて下書き/停止状態に取り込む。既存購読者へ最初のステップを再配信しない。配信済み位置を取得できない場合は移行を保留する。商品価格・決済状態を推測しない。全件数と原本ハッシュを照合し、未対応項目を確認した後に有効化する。

取得した実データはゆとり専用の非公開保管とし、買い切り商品の配布ZIPには絶対に含めない。
