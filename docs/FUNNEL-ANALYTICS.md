# ファネル分析・A/Bテスト・登録経路（2026-10-14追加）

## 計測の仕組み

- 公開ページ（`/shop/...`）を開くと、Workerが匿名の訪問者ID（Cookie `akh_v`、1年、HttpOnly、個人情報なし）を発行します。
- ページ表示後にブラウザから1回だけ計測（`/api/track`）を送ります。Cookieがない・別サイトからの送信・他店舗のページは記録しません。
- 読者登録・申込の時点で「直近30日に同じページ（パターン含む）を見た記録」を紐づけ、顧客（初回のみ）と注文に `attribution`（ref / utm_source / utm_medium / utm_campaign / 表示したパターン）を保存します。

## 分析タブ

| 指標 | 内容 |
| --- | --- |
| 訪問 | ページ表示の回数 |
| ユニーク | 訪問者ID（ブラウザ）単位。同じ人でも端末が違えば別 |
| 登録 / 申込 / 入金 | 読者登録、注文作成、うち入金済み |
| 売上 | 入金済み注文の金額（継続課金は初回分） |
| 登録率・購入率 | 登録÷ユニーク、入金÷ユニーク |

期間（7日・30日・90日・全期間）で絞り込み、ページごとに「A/Bパターン別」「経路別」の内訳を表示します。

## 登録経路（UTAGEの登録経路に相当）

同じページのURLに `?ref=経路名` を付けて配るだけです（分析タブで作成・コピーできます）。広告の `utm_source` などもそのまま集計します。経路ごとに別ページを複製する必要はありません。

## A/Bテスト

1. ページ一覧のフラスコのボタンで「A/Bパターン（下書き）」を作成（元のページを含めて最大5パターン）。
2. パターンを編集して公開すると、**元のページのURL**で訪問者ごとに振り分けます。同じ人には常に同じパターンを表示します（Cookie単位）。
3. 表示比率は各ページの「表示の比率（1〜100）」で調整できます。
4. 結果は分析タブで比較。終了するときは負けたパターンを下書きに戻すか、「A/Bテストから外す」。計測データは残ります。

注意：テスト中にパターンを編集すると結果が混ざります。パターンのフォーム・次のページ・オーダーバンプ等は、それぞれのパターンの設定が使われます。

## 分岐（ファネル）

- 販売ページ → アップセル（購入した／断った で別ページへ。ダウンセルも可）→ 完了ページ。
- オーダーバンプを同時購入した人だけ別の完了ページへ。
- 読者登録 → タグ → ステップ配信、メールのクリック・開封で条件分岐（docs/MAIL.md）。

自由配置のキャンバス型フロー図や、任意条件の分岐ツリーは未実装です。
